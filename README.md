# Subway Builder Paris IdFM Train Pack

Subway Builder IdFM-Pack is a mod for the game Subway Builder that adds trains from the Paris Metropolis. This pack contains metro, RER, Transilien and Light Rail vehicles.

Create lines with the tracks rails\&stations, then configure the lines with the vehicles. See belove the compatibility of tracks. The tracks themselves replace the base game vehicles (Heavy Metro become MP, Light Metro become MF, Commuter become North/East train tracks, Diesel Commuter become West/South train tracks, LRT become Dualis Tram-Train and Tram become Citadis Tram).
